# Trend Micro Vision One Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь:
SOC-аналитик или security engineer в организации на Trend Micro Vision One,
впервые открывающий приложение — обычно в момент разбора очереди Workbench
алертов или настройки нового окружения защиты.

## 1. Credential type
Region (регион дата-центра тенанта: us/eu/in/au/sg/jp) + Authentication
Token, сгенерированный в Vision One Console > Administration > API Keys —
токен статичный Bearer, не требует OAuth2-обмена.

## 2. Идеальный флоу (без ограничений SDK)
1. **Region как явное отдельное поле с выбором из списка** — у Vision One
   нет общего API-хоста, тенант физически живёт в одном из нескольких
   дата-центров; без явного выбора региона запросы уйдут не туда и
   вернут либо 404, либо данные не того тенанта.
2. **Проверка подключения реальным вызовом перед сохранением** — лёгкий
   `GET /v3.0/xdr/workbench/alerts?top=1` сразу после ввода credentials,
   чтобы поймать неверный токен/регион до сохранения.
3. **После успеха — сразу workbench snapshot** — количество открытых
   алертов по severity (critical/high/medium/low), endpoints с активной
   изоляцией, и последние Suspicious Object блокировки, чтобы дать
   wow-moment сразу после подключения.
4. **Явное предупреждение перед isolate_endpoint** — изоляция обрывает
   сетевой доступ хоста почти мгновенно; идеально — модальное
   подтверждение с именем эндпоинта перед вызовом.
5. **Явное разграничение log vs block при создании Suspicious Object** —
   если пользователь не укажет явно `scan_action=block`, объект по
   умолчанию должен быть в режиме мониторинга (`log`), чтобы не
   заблокировать легитимный трафик по ошибке (см. app.py docstring).
6. **Понятные сообщения на 401 vs 403** — 401 значит неверный/протухший
   токен, 403 значит, что у токена нет нужного scope (Vision One API Keys
   имеют предоставляемые роли — Full Access, Custom с конкретными
   permissions) — а не голый HTTP-код.
7. **Docs-ссылка прямо в форме подключения** — ссылка на страницу Trend
   Micro automation/API developer portal, чтобы не заставлять
   пользователя гуглить, где искать API Keys.

## 3. Wow-moment для демо
Подключил тенант → сразу видно: N открытых critical/high алертов в
Workbench, M эндпоинтов в изоляции, последние Suspicious Object
блокировки — без единого дополнительного клика.
